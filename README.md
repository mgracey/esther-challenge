# esther-challenge
Developed in Angular 19, using Angular Material UI component library and Highcharts.

* Running the application
  * Have deployed my challenge attempt on my own server at https://esther.michael-gracey.com/
  * To run locally, run `npm install` and `ng serve` before hitting localhost:4200

* Features:
  * Can add tasks by clicking the + button.
  * Can edit tasks by clicking on a task. Can also mark as complete by clicking the check button.
  * Can delete tasks by clicking on the x button.
  * Can sort tasks according to Title or Create date.
  * Chart analytics update in real time.
  * Visual distinction between completed and non completed tasks.
  * Loading spinner no data message & error handling where appropriate.
  * Fully responsive layout for desktop and mobile.
  * Form validation on task input.
  * Keyboard accessible, can perform all the basic functionality without the use of a mouse. 
  * Saves all updates in memory to reduce requests on the server, no need for GET requests after each update.
